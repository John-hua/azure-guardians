# Island Kit V2

Warm cozy island terrain and village prop kit generated for the Royal Revolt / Tiny Swords style prototype.

## Sheets

- `grass-cliff-platforms-v2.png` - rounded grass platforms, cliff edges, plateau chunks.
- `warm-green-forest-v2.png` - summer forest clusters, green trees, shrubs, flowers, logs, stumps. No snow caps.
- `village-paths-water-v2.png` - stone/dirt paths, small bridges, pond/water edge pieces, ground patches.
- `village-buildings-props-v2.png` - small medieval village houses, tower, well, market, fence, crates, campfire, planters.
- `ruins-rocks-deco-v2.png` - ruins, rocks, cave, worn stone floors, planks, debris, banners.

Each sheet has true alpha transparency. The matching `*-source.png` files preserve the original generated sheet.

## Component Folders

Every sheet is also auto-cropped into individual PNGs under a folder with the same base name. See `island-kit-v2-manifest.json` for component counts, dimensions, and source bounding boxes.
