# Grass Tile Set

Three 256x256 seamless grass terrain tiles for the island kit.

- `grass-tile-base.png` - warm painterly grass base.
- `grass-tile-variation-A.png` - same border as base, with small white/yellow flowers in the interior. Intended random rate: 15%.
- `grass-tile-variation-B.png` - same border as base, with worn dirt and small stones in the interior. Intended random rate: 10%.

Preview files:

- `grass-tile-base-seam-3x3.png`
- `grass-tile-mixed-seam-3x3.png`

All files are PNG RGBA. Terrain pixels are opaque; the alpha channel is present for engine consistency.
