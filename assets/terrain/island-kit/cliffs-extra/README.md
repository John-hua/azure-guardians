# Cliffs Extra

Supplementary cliff pieces for building all four island sides, matching the existing `island-cliffs-plateaus` style.

Files:

- `cliff-top-edge.png` - 200x120, north/top edge.
- `cliff-left-edge.png` - 120x200, west/left edge.
- `cliff-right-edge.png` - 120x200, east/right edge.
- `cliff-corner-tl.png`, `cliff-corner-tr.png`, `cliff-corner-bl.png`, `cliff-corner-br.png` - 160x160 convex outside corners.

All files are PNG RGBA with true alpha transparency. `cliffs-extra-source.png` is the generated source sheet; `cliffs-extra-source-alpha.png` is the cleaned transparent source sheet.
