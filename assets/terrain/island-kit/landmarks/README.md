# Landmarks

Large painterly isometric map landmarks for the island kit.

- `landmark-stone-arch.png` - ancient stone arch gate.
- `landmark-shrine.png` - small shrine / altar.
- `landmark-windmill.png` - village windmill.
- `landmark-mushroom-grove.png` - giant mushroom grove.
- `landmark-crystal-cluster.png` - blue-purple crystal cluster.

Each file is an individual PNG RGBA with true alpha transparency, sized between 256 and 384 px. See `landmarks-preview.png` and `landmarks-manifest.json`.
