# Biome Floor Textures

Four 512x512 painterly seamless floor textures for large-map biome separation.

- `biome-forest-floor.png` - deep green moss and fallen leaves.
- `biome-village-floor.png` - short grass with trampled marks.
- `biome-mine-floor.png` - warm sandy yellow dirt and stones.
- `biome-ruins-floor.png` - gray-green mossy cracked stone slabs.

Each file is PNG RGBA, 512x512, four-way seamless, with opaque terrain pixels. See `biomes-preview.png` and individual `*-seam-2x2.png` previews.
